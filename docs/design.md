# Vico 디자인

밝은 회색 바탕에 흰 카드, 인디고 포인트 색, 숫자와 코드는 모노 폰트를 쓰는 깔끔한 개발 도구 느낌이에요.
디자인 시안 캔버스: https://claude.ai/artifact/B6eWdyLqdNiXyCXqZH1YaT (맨 윗줄 "Vico MVP 화면" 네 개가 기준). 캔버스와 이 문서가 다르면 **이 문서가 기준**이다. 캔버스에 접근할 수 없어도 이 문서만으로 구현할 수 있어야 한다.

## 1. 디자인 토큰

`src/styles/global.css`의 `@theme`에 CSS 변수로 등록해서 사용한다 (예: `bg-surface`, `text-text-muted`, `bg-active-bg`). Tailwind v4는 `tailwind.config` 대신 CSS `@theme`로 토큰을 정의하기 때문.

### 글꼴

- 본문: `Pretendard Variable` (400, 500, 600, 700). npm `pretendard` 패키지의 dynamic-subset CSS를 `global.css`에서 불러와 빌드에 포함한다 (Google Fonts에 없어서. 외부 CDN에 기대지 않기 위함)
- 숫자, 아이디, 코드, 로고: `JetBrains Mono` (500, 700)
- `JetBrains Mono`는 Google Fonts에서 불러온다.

## 2. 공통 컴포넌트 (src/components)

| 컴포넌트 | 설명 |
| --- | --- |
| `Header` | 왼쪽 로고 `vico_` (모노, `_`만 accent) + "바이브 코딩 프로젝트 보드". 오른쪽 메뉴: 프로젝트, 내 프로필(MVP에서는 숨김, 아래 참고), 프로젝트 등록하기(accent 버튼). 현재 페이지는 muted 배경 |
| `StatusBadge` | 상태 색 표의 글자/배경, 12px/600, 패딩 3px 8px, 둥글기 6px. 옵션으로 "· 3일 전" 덧붙임 |
| `RecruitBadge` | "모집 중", accent-text / accent-soft |
| `ToolBadge` | 12px, muted 배경, text-sub |
| `Avatar` | 28px 정사각, 둥글기 8px, 아이디 영문 앞 2글자 대문자 |
| `StepBar` | 체크리스트 항목 수만큼 칸을 나눈 막대. 칸 높이 6px, 간격 3px, 완료 칸은 상태의 진행률 색. 항목이 `maxStepBarItems`(20)개를 넘으면 일반 진행률 바로 대체. 항목이 0개면 빈 진행률 바. `aria-label="체크리스트 N개 중 M개 완료"` |
| `ProgressRing` | 상세 화면용 원형 진행률 (지름 132px, 두께 12px) |
| `ProjectCard` | 아래 3.1 참고 |
| `RecruitCard` | 모집 포지션 칩 + 제목 + "@아이디 · 진행률 N%". accent-line 테두리 |
| `FilterBar` | 상태 탭, 검색창, 도구 칩, 정렬 칩 (React, `client:load`) |
| `Stat` | 숫자(모노 22px) + 라벨(12px) 카드 |
| `Banner` | deep 배경 배너 (제목, 설명, 흰 버튼) |
| `EmptyState` | 점선 테두리, "조건에 맞는 프로젝트가 없어요" |

"내 프로필"은 로그인이 없으므로 MVP 헤더에서 뺀다. 프로필은 카드의 `@아이디`를 눌러서 들어간다.

## 3. 화면

### 3.1 메인 `/`

위에서부터:

1. **소개 + 하이라이트** (2열, 좁으면 세로로 쌓임)
   - 왼쪽: h1 "지금 만들고 있는<br>바이브 코딩 프로젝트", 문장 "오늘 {진행중 수}개 프로젝트가 진행 중이고, {모집 수}개가 같이 만들 사람을 찾고 있어요.", Stat 4개(등록 / 지금 활발 / 팀원 모집 / 완성)
   - 오른쪽: 하이라이트 카드 (F-15, deep 배경). 라벨 "방금 체크리스트를 완료한 프로젝트" + `lastCompleted.at`의 상대 시각, 제목, 소개, StepBar(완료 칸은 `#A5B4FC`, 방금 완료한 칸은 mint), "방금 완료: {항목}", 진행률(완료 상태면 "완성!"), @아이디, 모집 정보, 스타. 카드 전체가 상세 링크. 대상이 없으면 오른쪽 영역을 숨기고 왼쪽이 전체 폭.
2. **같이 만들 사람을 찾고 있어요** (휴면이 아닌 모집 프로젝트가 있을 때만)
   - RecruitCard 그리드 (최대 3개, 최근 활동순, 휴면 제외). 오른쪽 "모집 중만 보기" 버튼 → 아래 탭을 팀원 모집으로 바꾸고 목록으로 스크롤.
3. **모든 프로젝트**
   - FilterBar: 탭 진행중(기본)/팀원 모집(휴면 제외)/완성작/휴면 + 개수, 검색, 도구 칩(전체 + 데이터에 있는 알려진 도구 + 필요하면 "기타", spec F-04), 정렬 칩(최근 업데이트/스타/진행률)
   - 카드 그리드 `repeat(auto-fill, minmax(300px, 1fr))`, 간격 16px
   - 진행중 탭은 활발 → 잠잠 순으로 묶은 뒤 정렬 기준 적용
   - 결과 없으면 EmptyState
4. **등록 배너**: "내 프로젝트도 여기 올려 보세요" / "VICO.md 하나와 PR 한 번이면 끝이에요." / 버튼 "등록 방법 보기" → `/join`
5. 푸터: "3시간마다 GitHub에서 확인해요 · 마지막 데이터 변경 {generatedAt}", 참여 가이드 링크. (변경이 없으면 커밋하지 않으므로 `generatedAt`은 "마지막 확인"이 아니라 "마지막 변경" 시각이다)

**ProjectCard** (카드 전체가 상세 링크):
- 1줄: Avatar + `@아이디`(모노 13px) / 오른쪽 StatusBadge "활발 · 오늘"
- 제목(17px/700) + 모집 중이면 RecruitBadge
- 소개 (14px, 2줄 말줄임)
- StepBar
- "다음 할 일: {nextTask}" (완료면 "체크리스트 완료", 체크박스가 0개면 "체크리스트가 비어 있어요") / 오른쪽 진행률 %(모노 700)
- 구분선 아래: ToolBadge들 / 오른쪽 "★ {stars}"

상대 시각: 빌드 시각 기준 경과일(spec 4절)이 0이면 "오늘", 그 외 "N일 전". 사이트는 하루 한 번 다시 빌드된다.

### 3.2 프로젝트 상세 `/p/[owner]/[repo]`

한 칸 레이아웃(최대 960px), 사이드바 없음.

1. "← 프로젝트 목록" 링크
2. **요약 카드**: 왼쪽 ProgressRing(가운데 "60%" + "6 / 10"), 오른쪽 상태 뱃지("활발 · 1일 전 업데이트"), 모집 뱃지, 제목(28px), 소개, `@아이디` · 도구 · 언어 · ★, 버튼 "레포 보기"(테두리) "데모 열기"(검정, demo 있을 때만)
3. **다음 할 일** 띠 (accent-soft 배경): "다음 할 일" 라벨 + 항목 + "VICO.md의 첫 번째 미완료 항목". 완료면 숨김
4. **진행 체크리스트**: 단계마다 단계 이름(없으면 생략) + 얇은 진행률 바 + "M/N", 항목은 2~3열 그리드. 완료 항목은 회색 배경에 체크 아이콘, 미완료는 흰 배경 테두리
5. **팀원 모집 배너** (모집 중일 때만, deep): "이 프로젝트는 팀원을 찾고 있어요", 포지션 칩, 연락처, 버튼 "#팀원모집에서 이야기하기"(디스코드 초대 링크는 config)
6. **README 뱃지**: 뱃지 미리보기 + 마크다운 코드 + "복사" 버튼
7. **비슷한 프로젝트** (있을 때만): 작은 카드 3개
8. "정보는 3시간마다 레포의 VICO.md에서 갱신돼요."

### 3.4 참여하기 `/join`

1. h1 "세 단계면 등록 끝" + "회원가입은 없어요. 레포에 VICO.md를 두고, 명단에 한 줄을 추가하는 PR만 보내면 돼요."
2. 번호 단계 카드 3개
   1. 레포 루트에 VICO.md 만들기 — 템플릿 코드 블록(어두운 배경) + 복사 버튼 + "contact에는 디스코드 아이디나 오픈카톡 링크만 적어 주세요."
   2. projects.json에 레포 주소 추가해서 PR 보내기 — 예시 코드 + "projects.json 열기" 버튼(GitHub 편집 링크)
   3. 자동 검사 통과하면 승인 후 3시간 안에 등장 — 검사 조건 4개 체크 리스트 (VICO.md 형식 / 체크리스트 3개 이상 / 공개 레포 / 아이디당 진행중 3개 이하). "처음 PR을 보내면 관리자가 검사 실행을 승인한 뒤에 결과가 달려요."
3. deep 배너 "등록하면 README 뱃지도 생겨요" + 뱃지 미리보기
4. 활동 상태 표 (상태 뱃지 / 기준 / 어디에 보이나요)
5. 자주 묻는 질문 (`<details>`): 코드는 비공개로 두고 싶어요 / 정보를 고치고 싶어요 / 프로젝트를 내리고 싶어요 / 봇이 이슈를 열었어요 ("30일 동안 업데이트가 없으면 `vico-bot-kr`이 알림 이슈를 한 번 열어요. 닫아도 되고, 다시 업데이트하면 알림 주기가 초기화돼요. 이슈 기능을 꺼 두면 알림을 받지 않아요.")
6. 안내 문구: "contact에 적은 연락처는 공개 레포와 Vico에 공개돼요."

### 3.5 뱃지 SVG `/badge/[owner]/[repo].svg`

- 높이 20px, 왼쪽 `vico` (배경 `#111827`, 흰 글자), 오른쪽 `{progress}% · {상태}` (배경: 활발 `#4F46E5`, 잠잠 `#8A5A00`, 휴면 `#6B7280`, 완료 `#1F7A3E`, 흰 글자). 흰 글자 대비가 모두 4.5:1 이상이 되도록 고른 값 (이전 잠잠 `#B7791F` 3.6:1, 완료 `#2F9E55` 3.4:1은 기준 미달)
- 글꼴은 `Verdana, sans-serif` 11px (SVG 안에서 웹폰트 사용 안 함). 한글 상태명 폭을 고려해 오른쪽 폭은 글자 수 기반으로 계산
- `<title>`에 "Vico 진행률 60% 활발"

## 4. 반응형

- 640px 이하: 소개/하이라이트 세로 배치, Stat 4개는 2×2, 카드 1열, FilterBar 요소 줄바꿈, 헤더 메뉴는 로고 + 등록 버튼만
- 상세 체크리스트 그리드는 자동으로 1열
- 가로 스크롤이 생기면 안 된다 (코드 블록만 내부 스크롤 허용, 스크롤되는 코드 블록은 키보드로 포커스할 수 있게)

## 5. 접근성

- 모든 페이지 맨 앞에 "본문으로 건너뛰기" 링크 (Tab을 처음 누르면 보임, `#main`으로 이동). 메인에서 필터까지 Tab 9번이 걸려서 추가
- 포커스 표시는 accent 2px 테두리. 카드는 제목 링크에 포커스했을 때만 카드 전체에 링 (안쪽 @아이디 링크는 자기 테두리만)
