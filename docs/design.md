# Vico 디자인

"인디고 나이트": 아주 어두운 남색 바탕에 인디고 버튼과 민트 포인트, 숫자와 코드는 모노 폰트를 쓰는 개발 도구 느낌이에요. 사이트 전체가 다크 테마 하나만 쓴다 (라이트/다크 전환 없음).
2026-11-12 변경: 처음의 밝은 테마가 밋밋하다는 의견으로 다크 테마와 새 메인 구성(큰 슬로건, 방금 체크한 항목 띠, 타일 묶음)으로 바꿨다. 토큰 이름은 그대로 두고 값만 바꿔서 다른 페이지도 같이 바뀐다.
처음 디자인 시안 캔버스: https://claude.ai/artifact/B6eWdyLqdNiXyCXqZH1YaT (밝은 테마 시절). 캔버스와 이 문서가 다르면 **이 문서가 기준**이다. 캔버스에 접근할 수 없어도 이 문서만으로 구현할 수 있어야 한다.

## 1. 디자인 토큰

`src/styles/global.css`의 `@theme`에 CSS 변수로 등록해서 사용한다 (예: `bg-surface`, `text-text-muted`, `bg-active-bg`). Tailwind v4는 `tailwind.config` 대신 CSS `@theme`로 토큰을 정의하기 때문.

### 아바타 색 (아이디 순서대로 순환)

`#2B2870/#C7C4FF`, `#133A2E/#A5F3C4`, `#3A2C12/#F5C77E`, `#232C6B/#A5B4FC`, `#3D1630/#F9A8D4`, `#0F3534/#99F6E4` (배경/글자). 아이디 문자열 해시로 고정 배정한다.

### 배경 효과

- 점 격자: `radial-gradient(rgba(199,196,255,.13) 1px, transparent 1px)`, 22px 간격. 메인 첫 화면에만.
- 빛: 첫 화면 위쪽에 인디고(`rgba(99,102,241,.42)`)와 민트(`rgba(165,243,196,.14)`) 원형 그라데이션 두 개를 겹친다. 장식이라 `pointer-events: none`.

### 글꼴

- 본문: `Pretendard Variable` (400, 500, 600, 700). npm `pretendard` 패키지의 dynamic-subset CSS를 `global.css`에서 불러와 빌드에 포함한다 (Google Fonts에 없어서. 외부 CDN에 기대지 않기 위함)
- 숫자, 아이디, 코드, 로고: `JetBrains Mono` (500, 700)
- `JetBrains Mono`는 Google Fonts에서 불러온다.

## 3. 화면

### 3.1 메인 `/`

위에서부터:

1. **첫 화면 `Hero`** (가운데 정렬, 위아래 여백 넉넉히, 점 격자 + 빛 배경)
   - 알약 (하이라이트 대상이 있을 때만, spec F-15): mint 점 + "방금 완료 · **{제목}** — {lastCompleted.text}" + mint 바탕 "보기 →". 알약 전체가 상세 링크
   - 슬로건 h1 "혼자 만들어도,<br>같이 보이게" + 깜빡이는 mint 커서 `_` (`prefers-reduced-motion`이면 깜빡이지 않음). 둘째 줄은 deep-step → deep-label → `#EEEDFE` 그라데이션 글자
   - 소개 (17px, text-muted): "Vico는 바이브 코딩 프로젝트 보드예요. 레포에 **VICO.md** 하나만 두면 진행률, GitHub 스타, 활동 상태가 3시간마다 여기에 모여요."
   - 버튼: "내 프로젝트 올리기"(accent, `/join`) / "프로젝트 구경하기"(테두리, `#projects`)
2. **방금 체크한 항목 `CheckedStrip`** (대상이 있을 때만)
   - 작은 라벨 "방금 체크한 항목" 아래 한 줄: `[x]`(mint) {제목} · {항목}. 각 항목은 상세 링크
   - 대상: 휴면이 아니고 `lastCompleted`가 있는 프로젝트, `lastCompleted.at` 최근순, 최대 `checkedStripLimit`(8)개 (`lib/similar.ts` `getRecentlyChecked`)
   - 한 줄로 두고 넘치면 가로 스크롤 (스크롤바 숨김, 양 끝 흐림). 들어가면 가운데 정렬
   - 하이라이트 대상(`activeDays` 이내)과 달리 기간 제한은 없다. 오래된 완료라도 최근순으로 보여준다
3. **지금 만들어지는 중 `Overview`** — 제목 "지금 만들어지는 중" + text-muted "한눈에 보는 오늘의 Vico"
   - 3열 타일 (1024px 미만은 1열). 타일: surface 배경, border 테두리, 둥글기 16px, 안쪽 여백 22px
   - **숫자 타일** (프로젝트 타일이 있으면 2행 차지): 라벨 "등록된 프로젝트", 큰 숫자 `registered` (모노 120px/800, mint, 640px 이하 80px), "개의 프로젝트가 Vico에 있어요", 아래 줄마다 구분선: 지금 활발 / 팀원 모집 / 완성 개수. 오른쪽 아래 mint 빛
   - **프로젝트 타일** 최대 `overviewProjectTiles`(2)개: 하이라이트 대상(HighlightCard)을 먼저, 남은 자리는 휴면이 아닌 모집 프로젝트(RecruitCard, 최근 활동순, 하이라이트와 겹치면 제외). 1개뿐이면 2열을 차지한다
     - HighlightCard: @아이디 / mint 테두리 알약 "● 방금 완료 · {상대 시각}", 제목 22px/800, 진행률 44px 모노(완료 상태면 "완성!"), StepBar(완료 칸 deep-step, 방금 완료한 칸 mint), "✓ 방금 완료: {항목}", 모집 중이면 "모집 중 · {포지션}", ★. 타일 전체가 상세 링크
     - RecruitCard: @아이디 / deep-label 테두리 알약 "팀원 모집 중", 제목 22px/800, 진행률 44px, StepBar, "찾는 사람: {포지션}". 타일 전체가 상세 링크
   - **VICO.md 타일** (2열 차지): 왼쪽 "체크리스트가 곧 진행률" + "VICO.md의 체크박스를 채울 때마다 진행률이 올라가요. 따로 입력할 건 없어요." + "템플릿 보기 →"(`/join`). 오른쪽 짧은 VICO.md 예시 코드 (고정 문구)
3. **모든 프로젝트**
   - FilterBar: 탭 진행중(기본)/팀원 모집(휴면 제외)/완성작/휴면 + 개수, 검색, 도구 칩(전체 + 데이터에 있는 알려진 도구 + 필요하면 "기타", spec F-04), 정렬 칩(최근 업데이트/스타/진행률)
   - 카드 그리드 `repeat(auto-fill, minmax(300px, 1fr))`, 간격 16px
   - 진행중 탭은 활발 → 잠잠 순으로 묶은 뒤 정렬 기준 적용
   - 결과 없으면 EmptyState
4. **마지막 등록 권유** (가운데 정렬, 위에 border, 아래쪽 mint 빛): h2 "내 프로젝트도 올려 보세요" + 둘째 줄 text-muted "VICO.md 하나와 PR 한 번이면 끝." / 버튼 "등록 방법 보기" → `/join`
5. 푸터: "3시간마다 GitHub에서 확인해요 · 마지막 데이터 변경 {generatedAt}", 참여 가이드 링크. (변경이 없으면 커밋하지 않으므로 `generatedAt`은 "마지막 확인"이 아니라 "마지막 변경" 시각이다)

**ProjectCard** (카드 전체가 상세 링크):
- 1줄: Avatar + `@아이디`(모노 13px) / 오른쪽 StatusBadge "활발 · 오늘"
- 제목(20px/800) + 모집 중이면 RecruitBadge
- 소개 (14px, 2줄 말줄임)
- 진행률 (모노 36px/800, accent-text. 활발이 아니면 text-muted) / 오른쪽 "{done} / {total} 완료"
- StepBar
- "다음 할 일: {nextTask}" (완료면 "체크리스트 완료", 체크박스가 0개면 "체크리스트가 비어 있어요")
- 구분선 아래: ToolBadge들 / 오른쪽 "★ {stars}"

상대 시각: 빌드 시각 기준 경과일(spec 4절)이 0이면 "오늘", 그 외 "N일 전". 사이트는 하루 한 번 다시 빌드된다.

### 3.2 프로젝트 상세 `/p/[owner]/[repo]`

한 칸 레이아웃(최대 960px), 사이드바 없음.

1. "← 프로젝트 목록" 링크
2. **요약 카드**: 왼쪽 ProgressRing(가운데 "60%" + "6 / 10"), 오른쪽 상태 뱃지("활발 · 1일 전 업데이트"), 모집 뱃지, 제목(28px), 소개, `@아이디` · 도구 · 언어 · ★, 버튼 "레포 보기"(테두리) "데모 열기"(흰 바탕 + bg 글자, demo 있을 때만)
3. **다음 할 일** 띠 (accent-soft 배경): "다음 할 일" 라벨 + 항목 + "VICO.md의 첫 번째 미완료 항목". 완료면 숨김
4. **진행 체크리스트**: 단계마다 단계 이름(없으면 생략) + 얇은 진행률 바 + "M/N", 항목은 2~3열 그리드. 완료 항목은 muted 배경에 mint 체크 아이콘, 미완료는 surface 배경 테두리
5. **팀원 모집 배너** (모집 중일 때만, deep): "이 프로젝트는 팀원을 찾고 있어요", 포지션 칩, 연락처, 버튼 "#팀원모집에서 이야기하기"(디스코드 초대 링크는 config)
6. **README 뱃지**: 뱃지 미리보기 + 마크다운 코드 + "복사" 버튼
7. **비슷한 프로젝트** (있을 때만): 작은 카드 3개
8. "정보는 3시간마다 레포의 VICO.md에서 갱신돼요."

### 3.3 프로필 `/u/[id]`

1. **deep 배너**: Avatar(80px) + `@아이디` + "{registeredAt 중 가장 이른 달}부터 Vico에서 만드는 중" + Stat 3개(진행중 "2 / 3", 완성작, 받은 스타 합계) + "GitHub 프로필" 버튼
2. **진행중인 프로젝트**: ProjectCard와 같은 스타일. 3개 미만이면 마지막에 점선 카드 "프로젝트 하나 더 올리기 / N자리 남았어요" → `/join`
3. **완성작**: 한 줄 카드 (제목, 완료 뱃지, 소개, ★)
